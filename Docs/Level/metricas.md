# Métricas do jogador

Unidade: **tiles** (1 tile = 16 px = 1 unidade Unity). Preencher na **Fase 1**, medindo na cena `Playground` com os valores de `PlayerMovementSettings`.

| Métrica | Valor (tiles) | Folga de design | Medido em |
|---|---|---|---|
| Altura do pulo simples | ? | desenhar até altura − 0,5 | |
| Distância do pulo simples correndo | ? | desenhar até distância − 1 | |
| Altura com pulo duplo | ? (pós-MVP) | | |
| Distância com dash | ? (pós-MVP) | | |
| Altura do gato em pé | ~1,4 (≈22 px) [PROPOSTA] | | |
| Altura do gato agachado | ? (deve ser < 1) | passagem baixa = 1 tile | |
| Alcance de visão do inimigo (claro / escuro) | ? / ? (Fase 3) | | |

Como medir: suba nos degraus da Playground (1 a 6 tiles) e tente os buracos (2 a 5 tiles). O maior degrau e o maior buraco vencidos **com folga** viram os valores acima.
